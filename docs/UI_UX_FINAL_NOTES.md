# Catatan UI/UX Final KosKu

Fokus perapihan terakhir:

1. Halaman user dibuat lebih fokus ke pencarian kos, bukan dashboard administratif.
2. Detail kos diperkuat sebagai halaman pengambilan keputusan: foto, harga, ringkasan kamar, lokasi, maps, fasilitas, CTA booking, dan WhatsApp pemilik.
3. Pembayaran dibuat lebih jelas dengan ringkasan kos, kamar, status, jatuh tempo, upload bukti, dan preview.
4. Empty state dibuat lebih informatif agar halaman kosong tidak terlihat seperti error.
5. CTA utama dibuat jelas: Cari Kos, Lihat Detail, Ajukan Sewa, Upload Bukti Pembayaran.
6. Gaya visual dijaga konsisten: warna netral, biru sebagai aksen, radius moderat, shadow halus, dan font-weight tidak berlebihan.

Saat presentasi, tekankan bahwa desain dibuat agar alur user sederhana: cari kos -> detail kos -> ajukan sewa -> pembayaran -> review.
